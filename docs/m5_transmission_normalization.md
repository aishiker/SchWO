# M5 Transmission Normalization

Date: 2026-07-06

Status: M5a/T1 frozen design, pending T7aa independent review.  This document
freezes Q005 terminology and normalization only.  It does not implement
solver, plotting, CLI, artifacts, or tests.

## 1. Scope

M5 user-facing outputs need a finite-radius pointwise comparison between the
Schwarzschild-scattered wave field and the corresponding no-lens flat wave
field.  The production observable is therefore a pointwise wave-optics
amplification factor:

```text
F = h_lensed / h_unlensed
```

Here `h_lensed` means the already validated finite-radius production
polarization field `h_plus/h_cross`, extracted with the frozen Route B
incident-frame electric-tidal packaged-polarization bridge.

The following quantities are not this M5 pointwise factor:

- radial horizon transmission amplitude;
- radial absorption probability or flux coefficient;
- `A_in`, `A_out`, phase shift, Wronskian, or horizon flux diagnostics from
  RW/Zerilli mode matching;
- asymptotic scattering cross sections or Kirchhoff/scalar approximations.

Those radial/asymptotic quantities remain diagnostics or future observables
and must use names such as `radial_mode_transmission`,
`radial_horizon_transmission`, `radial_absorption`, or `phase_shift`, never
bare `transmission` in M5 finite-radius output metadata.

## 2. Production Names

The production pointwise complex component ratios are:

```text
F_plus_complex(k, r, theta, phi)
  = h_plus_lensed(k, r, theta, phi)
    / h_plus_unlensed(k, r, theta, phi)

F_cross_complex(k, r, theta, phi)
  = h_cross_lensed(k, r, theta, phi)
    / h_cross_unlensed(k, r, theta, phi)
```

These are complex amplitude ratios.  They retain both amplitude and phase.
They are the authoritative componentwise `F_plus` and `F_cross` objects for
production.  If a shorter public label is later exposed, `F_plus` and
`F_cross` must mean these complex quantities unless the field name explicitly
says `amplitude` or `intensity`.

Derived component summaries are allowed but secondary:

```text
amplification_plus  = abs(F_plus_complex)
amplification_cross = abs(F_cross_complex)

intensity_plus_ratio  = abs(F_plus_complex)^2
intensity_cross_ratio = abs(F_cross_complex)^2
```

The combined polarization norm is the preferred scalar plot summary when a
single non-negative map is needed:

```text
H_norm_lensed
  = sqrt(abs(h_plus_lensed)^2 + abs(h_cross_lensed)^2)

H_norm_unlensed
  = sqrt(abs(h_plus_unlensed)^2 + abs(h_cross_unlensed)^2)

F_pol_norm = H_norm_lensed / H_norm_unlensed

I_pol_ratio = H_norm_lensed^2 / H_norm_unlensed^2
```

`F_pol_norm` and `I_pol_ratio` are real non-negative scalar summaries.  They
do not replace the complex component ratios and must carry their own
denominator mask.

## 3. Unlensed Baseline

The unlensed baseline is the flat/no-lens production-compatible
polarization field with exactly the same external convention as the lensed
field:

```text
h_unlensed(k, r, theta, phi; A_plus, A_cross)
```

It must use:

- the same Fourier convention `exp(-i k t)`;
- the same positive `k`;
- the same input complex amplitudes `A_plus` and `A_cross`;
- the same observer coordinates and coordinate conversion, including the
  same `r,theta,phi` derived from an x-z grid;
- the same incident direction convention, currently `+z`;
- the same incident tetrad and polarization convention;
- the same Route B packaged-polarization bridge used by production
  `h_plus/h_cross`.

For the current `+z` plane wave, the baseline phase is:

```text
h_plus_unlensed  = A_plus  exp(i k z)
h_cross_unlensed = A_cross exp(i k z)
z = r cos(theta)
```

The production baseline path is the existing flat/no-lens
production-compatible polarization path:

```text
compute_flat_no_lens_polarization(...)
```

or a future API with the same contract.  The baseline must not be generated by
a tiny-`M` Schwarzschild solve, by imposing a Schwarzschild horizon boundary,
by a radial RW/Zerilli solve, or by radial phase-shift extraction.  The
diagnostic partial-wave flat path may be used for tests, but not as the M5
production denominator unless a later reviewed design explicitly replaces the
baseline API.

For x-z saved grids, the lensed result's valid mask still controls where a
ratio is meaningful.  The flat baseline itself has no horizon, but M5 ratios
are saved only on valid lensed-grid points; invalid Schwarzschild points keep
the existing invalid-field policy.

## 4. Denominator-Zero Policy

Component denominators may vanish by physical polarization choice.  For
example, a pure plus input has `h_cross_unlensed = 0` everywhere, while
`h_plus_unlensed` may be perfectly regular.  Component masks are therefore
independent.

Define input and grid scales:

```text
A_scale = max(abs(A_plus), abs(A_cross), tiny)
plus_grid_scale  = max_valid(abs(h_plus_unlensed))
cross_grid_scale = max_valid(abs(h_cross_unlensed))
norm_grid_scale  = max_valid(H_norm_unlensed)
```

The default denominator thresholds are:

```text
eps_plus  = max(1e-14 * A_scale,  1e-12 * plus_grid_scale)
eps_cross = max(1e-14 * A_scale,  1e-12 * cross_grid_scale)
eps_norm  = max(1e-14 * A_scale,  1e-12 * norm_grid_scale)
```

`tiny` is the floating-point positive tiny value for the output dtype.  The
`max_valid` reduction uses only lensed-grid valid points with finite baseline
values.  If a grid scale is zero, its second term is zero and the absolute
`1e-14 * A_scale` term controls.  If `A_plus=A_cross=0`, all denominator masks
are false and all ratios are NaN; production should reject or clearly label
this as a zero-incident-amplitude diagnostic case rather than a physical
amplification map.

Masks are:

```text
valid_ratio_plus_mask  = valid_lensed_mask
                         and isfinite(h_plus_unlensed)
                         and abs(h_plus_unlensed) > eps_plus

valid_ratio_cross_mask = valid_lensed_mask
                         and isfinite(h_cross_unlensed)
                         and abs(h_cross_unlensed) > eps_cross

valid_ratio_norm_mask  = valid_lensed_mask
                         and isfinite(H_norm_unlensed)
                         and H_norm_unlensed > eps_norm
```

Policy:

- `F_plus_complex` is complex NaN where `valid_ratio_plus_mask` is false.
- `F_cross_complex` is complex NaN where `valid_ratio_cross_mask` is false.
- `F_pol_norm` and `I_pol_ratio` are real NaN where
  `valid_ratio_norm_mask` is false.
- Plus and cross ratios are allowed to be NaN independently.
- Do not clip, floor, or regularize denominators to force finite ratios.
- Do not fill masked component ratios with zero or one.
- Save masks and threshold values in metadata.

## 5. Required Metadata

M5 result files must include normalization metadata sufficient to reproduce
the denominator and reject convention drift:

```text
normalization.kind = "pointwise_wave_optics_amplification"
normalization.version = "m5a_t1_v1"
normalization.baseline = "flat_no_lens"
normalization.baseline_api = "compute_flat_no_lens_polarization"
normalization.fourier = "exp(-i k t)"
normalization.incident_direction = "+z"
normalization.same_k = true
normalization.same_A_plus_A_cross = true
normalization.same_observer_coordinates = true
normalization.polarization_bridge = "Route B incident-frame electric tidal packaged scalars"
normalization.no_schwarzschild_horizon_boundary_in_baseline = true
normalization.no_tiny_M_baseline = true
normalization.excludes_radial_horizon_transmission = true
normalization.denominator_policy = "independent masks, NaN where denominator mask is false"
normalization.denominator_atol_factor = 1e-14
normalization.denominator_rtol_factor = 1e-12
normalization.eps_plus = ...
normalization.eps_cross = ...
normalization.eps_norm = ...
normalization.mask_fields = [
  "valid_ratio_plus_mask",
  "valid_ratio_cross_mask",
  "valid_ratio_norm_mask"
]
```

Saved arrays should include, at minimum, `F_plus_complex`,
`F_cross_complex`, `F_pol_norm`, `I_pol_ratio`, and the three masks above.
Derived component amplitude and intensity ratios may also be stored if they
are computed directly from the complex ratios and use the same masks.

## 6. Future Mandatory Tests

Before any M5 plot or artifact is accepted, T7/T8 must add tests covering:

1. No-lens identity: when the lensed path is replaced by the flat/no-lens
   baseline, valid `F_plus_complex`, `F_cross_complex`, and `F_pol_norm` equal
   one within the active numerical tolerance.
2. Baseline path guard: M5 denominator generation calls the flat/no-lens
   production-compatible baseline and does not call `solve_radial_mode`, does
   not impose a horizon boundary, and does not use tiny `M`.
3. Component zero handling: pure plus input masks only the cross component;
   pure cross input masks only the plus component; the unmasked component
   remains finite.
4. Combined norm handling: the norm ratio is finite when either polarization
   denominator is finite, and is NaN only when the combined baseline norm mask
   is false.
5. Metadata completeness: saved result metadata records the baseline API,
   Fourier convention, Route B bridge, denominator thresholds, mask field
   names, and explicit exclusion of radial horizon transmission.
6. Saved-schema round trip: NPZ/HDF5 readers preserve complex ratios, real
   scalar summaries, masks, NaNs, and normalization metadata.
7. Plot read-only boundary: transmission/amplification plotting reads saved
   ratio fields and masks only; it must not recompute the solver or flat
   baseline silently.
8. Direct-division regression: selected points compare saved ratios against
   direct division of saved lensed fields by independently evaluated
   flat/no-lens baseline fields.
9. Terminology guard: user-facing labels and metadata distinguish pointwise
   wave-optics amplification from radial `A_in/A_out`, phase-shift,
   horizon-transmission, and absorption diagnostics.

## 7. Diagnostic-Only Quantities

Radial `A_in/A_out`, phase factors, Wronskians, and horizon-flux absorption
belong to the radial RW/Zerilli scattering problem.  They may be used for
solver health, future absorption cross sections, or far-zone scattering
diagnostics.  They must not be used as the denominator or numerator of the
finite-radius M5 pointwise amplification factor.

Scalar/Kirchhoff/eikonal baselines and asymptotic helicity amplitudes are
also diagnostic or future-comparison tools unless a later T1/T7-reviewed
slice freezes a separate production observable.
