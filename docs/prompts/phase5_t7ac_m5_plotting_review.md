## 2. Review Checklist

Verify:

1. Plotting reads saved amplification results through the IO layer.
2. Plotting does not recompute unlensed baseline, pointwise ratios, radial
   modes, partial-wave sums, or polarization.
3. Quantity names are explicitly pointwise amplification quantities, not
   ambiguous radial transmission/absorption.
4. `F_pol_norm` and `I_pol_ratio` use `valid_ratio_norm_mask`.
5. plus/cross quantities use their independent component masks.
6. Invalid values remain NaN/masked; no zero/one/clipping/floor replacement is
   introduced.
7. Sidecar metadata records plot type, quantity, mask field, valid/invalid
   counts, source result path, normalization metadata, baseline metadata, grid
   kind, output path, and requested DPI.
8. CLI smoke uses synthetic/lightweight saved amplification results and does
   not trigger production solver work.
9. Existing wave-field plotting and IO tests still pass.
10. `src/schwgw/viz` remains read-only and has no imports/calls into solver,
    scattering, radial, angular, perturbation, background, baseline, or ratio
    computation modules.

## 4. Pass Conditions

Pass only if:

- all review checklist items pass;
- targeted tests and full pytest pass;
- static read-only boundary scan passes;
- no physics convention drift is found;
- `status.md` records changed files, commands, test results, open issues, and
  next action.

If passed, recommend the next slice as a T0 decision between:

```text
T8r M5 first archived amplification artifact from accepted M4-production saved results
```

and a more conservative synthetic/schema extension, if T7ac finds any
remaining plotting metadata ambiguity.

## 5. Stop Conditions

Stop and update `status.md` if:

- plotting recomputes any M5 ratio or baseline;
- plotting imports solver/scattering/radial physics modules;
- mask/NaN policy is wrong or ambiguous;
- sidecar metadata is insufficient to identify normalization and mask policy;
- tests fail;
- T8q changes M5/Q005/Q014/T4 conventions, thresholds, `lmax`, accepted M4
  artifacts, or production gates.
