## 目标

建立第一组接近 Li-Hou-Zhao 图像参数的 saved-result benchmark，但范围只限：

- `M=1`
- `r_obs=60M`
- `kM=1`
- `A_plus=0.9+1.1j`
- `A_cross=0.4+0.6j`
- fixed-radius angular diffraction line/small grid
- saved `.npz` result + read-only plots
- saved convergence metadata

这一步是 **Li Fig.4-like / Fig.4-lite**，不是完整论文级 Fig.3 spatial wavefield，也不是 R60_K2/R60_K4。不要实现 transmission factor。

## 允许修改

## 具体任务

1. 创建 `configs/r60_k1_li_fig4_lite.yaml`
   - 使用 R60_K1 fixture 已验证参数：

```yaml
case_id: R60_K1_LI_FIG4_LITE
output: /tmp/r60_k1_li_fig4_lite.npz
background:
  M: 1.0
wave:
  kM: 1.0
  A_plus:
    real: 0.9
    imag: 1.1
  A_cross:
    real: 0.4
    imag: 0.6
observer:
  r: 60.0
  theta_values: [0.0, 0.01, 0.02, 0.05, 0.1, 0.2, 0.4, 0.7, 1.0]
  phi_values: [0.0]
numerics:
  lmax: 108
  boundary:
    r_in_eps: 1.0e-6
    r_out: 120.0
    rtol: 1.0e-9
    atol: 1.0e-11
convergence:
  enabled: true
  lmax_values: [60, 72, 84, 96, 108]
  theta_values: [0.0, 0.05, 0.2, 1.0]
  phi_values: [0.0]
  selected_threshold: 1.0e-4
  near_axis_threshold: 1.0e-3
```

2. Run a runtime probe
   - First run the config once to `/tmp/t8d_r60_k1_li_fig4_lite.npz`.
   - If the run is clearly too slow for this thread, stop and record the timing/blocker in `status.md`.
   - Do not silently reduce `lmax` and still call the result `R60_K1_LI_FIG4_LITE`.

3. Inspect saved metadata
   - Confirm arrays:
     - `theta`
     - `phi`
     - `h_plus`
     - `h_cross`
     - `metadata_json`
   - Confirm `h_plus` and `h_cross` are complex arrays with shape `(9, 1)`.
   - Confirm `diagnostics.lmax_convergence_history` exists.
   - Confirm `diagnostics.final_lmax_pair == [96, 108]`.
   - Confirm `diagnostics.lmax_convergence_policy.final_pair_passed` is true.
   - Confirm `diagnostics.summary` includes finite numeric maxima.
   - Confirm any radial warnings, if present, are structured metadata and do not overwrite numeric diagnostics.

4. Generate read-only plots from the saved result
   - `h_plus abs`
   - `h_cross abs`
   - convergence history
   - Plots must be generated by `schwgw.cli plot-wavefield` and `schwgw.cli plot-convergence`, not by ad hoc physics code.
   - Save artifacts under `/tmp/`, not as committed repository files.

5. Optional HDF5 mirror
   - If `h5py` is available and runtime is still reasonable, run the same config to `/tmp/t8d_r60_k1_li_fig4_lite.h5`.
   - Confirm `plot-convergence` also works from HDF5.
