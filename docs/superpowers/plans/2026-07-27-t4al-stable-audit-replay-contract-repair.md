# T4al Stable Audit Replay Contract Repair Plan

## Goal

Replace the exhausted T4ak helper with a reviewed three-root helper whose
canonical audit payload is byte-identical before and after Phase-A0 capture
publication and can therefore be independently replayed by root T0.

## Task 1 — Independent Package Review

The existing T7 task reads the exact four-file T4al package, all four
immutable failed-helper roots, the frozen T4ai/T4aj/T4ak packages and
reviews, the live driver, v10/runtime/complete-290 evidence, complete
consumed witness, canonical state, absent units, external object, and
process/transient state.

Only exact:

```text
REVIEW GREEN / T0 STABLE AUDIT REPLAY CONTRACT REPAIR APPROVED
```

permits Task 2.

## Task 2 — Phase A0 Three-Root Helper Freeze

In the existing T4 task using `gpt-5.6-sol/high`:

1. fresh-verify the exact candidate/ref/parent/package and every upstream
   guard;
2. choose fresh pairwise-distinct helper, audit-record, and execution paths
   below the exact control root;
3. create helper and audit-record roots only; keep execution absent;
4. embed project/control/helper/audit-record/execution roots as five direct
   full `ast.Constant` strings;
5. publish and close the helper root before the first audit;
6. statically prove that the canonical audit payload binds the audit-record
   root only through the exact stable projection and excludes mutable
   metadata and children;
7. run audit-only exactly once under exact CPython 3.14;
8. prove exact no-newline canonical stdout, empty stderr, exit zero, no
   child write, unchanged helper root, and absent execution root;
9. publish all captures, a non-self-referential records index, and a
   terminal manifest only in the audit-record root; the terminal manifest
   binds the index and exact filename set but never claims its own digest
   or post-close timestamp;
10. verify durability, close the audit-record root read-only, and report
    terminal-manifest hash/stat plus post-close root identity for root-T0
    independent recording.

Do not run execute mode, create the execution root, copy the driver, publish
a before manifest, edit the driver, run preflight, or invoke science.

Return exactly:

```text
CHECKPOINT / T4AL STABLE AUDIT REPLAY HELPER FROZEN
```

Then pause.

## Task 3 — Root-T0 Independent Replay

Root T0 independently:

- reads the helper and every capture fully;
- parses AST and verifies the five constants, three-root separation,
  forbidden surfaces, and stable projection schema;
- recomputes all frozen evidence and witness/canonical guards;
- reruns audit-only once without writes using exact argv/cwd/environment;
- requires byte-identical stdout/digest, empty stderr, exit zero, unchanged
  helper/audit roots, and absent execution root.

Any mismatch stops. Complete PASS permits one digest-bound execute
authorization.

## Task 4 — One-Shot Preservation Execution

T4 runs the frozen helper once using the exact reviewed execute
argv/cwd/environment and expected audit digest. After the shared pre-write
audit and digest match, it creates only the reserved execution root and
publishes the old-driver snapshot, before manifest, execution result, and
launcher records there. Helper and audit-record roots remain untouched.

Any failure consumes authorization and stops without retry.

## Task 5 — Resume T4ai Phase A

Only preservation PASS permits:

1. the already reviewed artifact-local driver/test repair;
2. deterministic relocated benchmark identity binding;
3. Unicode-root positive and `ensure_ascii=False` negative coverage;
4. one fresh exact-Python-3.14 zero-science preflight;
5. scientific runner CLI / official audit / solver counts `0/0/0`.

On PASS return exactly:

```text
CHECKPOINT / RELOCATED BENCHMARK IDENTITY CONTRACT FROZEN
```

Then pause for root T0.
