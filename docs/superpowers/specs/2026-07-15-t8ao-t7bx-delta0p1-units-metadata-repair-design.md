## 3. Alternatives Considered

### 3.1 Chosen: two-stage gated repair, then later scientific design

First repair and independently accept the artifact contract. Only after T7bx
accepts the repair may T0 design adaptive sampling evidence.

Advantages:

- isolates metadata validity from scientific adequacy;
- permits exact old/new array comparison;
- prevents new computation from inheriting an invalid artifact contract;
- keeps the next implementation small and reversible.

### 3.2 Rejected: combine metadata repair and new 0.05 computation

This would mix artifact migration with new physics output, make provenance
ambiguous, and prevent a clean proof that the existing arrays were unchanged.

### 3.3 Rejected: proceed using inferable units

Frozen design Section 8.3 and T7bw check 3 require explicit metadata. Inference
cannot replace the recorded contract.

## 6. Migration Architecture

### 6.1 Read-only scientific boundary

The migration entry point accepts only the existing output directory. It must
not import or call:

- `compute_polarization`;
- `compute_flat_no_lens_polarization`;
- `solve_radial_mode`;
- `_FrequencyRadialCache`;
- `_compute_frequency`;
- the T8an runner.

Tests replace these callables with fail-on-call sentinels. Any call is a test
failure.

### 6.2 Durable pre-repair preservation

Before replacement, T8ao copies the exact 23 physical active files to:

```text
runs/phase5/fig5_fig6_delta0p1_risk_pilot/
  quarantine/t8ao_pre_units_metadata/
```

The backup preserves relative paths, file bytes, sizes, and SHA-256 values.
Existing runner-cache quarantine content is untouched.

The backup contains a repair ledger with:

- the frozen source manifest hash;
- all 23 physical source-file hashes, including the frozen manifest itself;
- the canonical non-metadata array fingerprint map;
- migration state;
- no scientific acceptance label.

If the exact backup directory already exists, every file must match before
resume. A mismatch stops the migration.

### 6.3 Canonical array fingerprints

For each non-`metadata_json` NPZ array, the repair computes:

```text
SHA256(np.save(array, allow_pickle=False) bytes)
```

The key is `<relative_npz_path>::<array_name>`. The sorted full mapping is
part of the metadata-contract hash.

Both before and after replacement, T8ao verifies:

- exact array-key set;
- shape;
- dtype;
- `np.array_equal`;
- canonical NumPy-array SHA-256.

No tolerance-based equality is permitted.

### 6.4 Atomic and resumable replacement

Replacement is file-atomic and journaled:

1. validate all frozen source hashes;
2. create or validate the durable backup;
3. write all candidate files under the repair staging area;
4. validate candidate units, ordering, provenance, hashes, and array identity;
5. mark staging complete;
6. replace active files with `os.replace`, updating the repair ledger after
   each file;
7. independently re-audit the complete active tree;
8. mark the repair ledger complete.

An interruption resumes from the ledger. It never recomputes scientific
values and never treats a partially migrated tree as accepted.

## 12. Failure And Recovery Rules

- Input hash, backup, array identity, units coverage, ordering, schema,
  provenance, test, scope, or forbidden-output failure stops T8ao.
- Scientific arrays are never repaired, rounded, recast, interpolated, or
  regenerated.
- A model-capacity/system interruption may resume the same T8 task only after
  the repair ledger and candidate/active hashes are checked.
- A contract or test failure is not recoverable by switching models.
- T7bx never fixes T8ao.

## 13. Boundary Of The Later Scientific Stage

Only after T7bx artifact-contract GREEN may T0 write a separate design for
adaptive scientific evidence.

That later design should evaluate:

- `0.05` midpoints
  `[0.35,0.45,0.85,0.95,1.55,1.65,2.85,2.95,3.85,3.95]`;
- the already-failing `0.05` edges
  `[1.7,1.75]`, `[2.75,2.8]`, and `[3.75,3.8]`;
- whether those three edges require `0.025` midpoint evidence at
  `[1.725,2.775,3.775]`;
- a refinement criterion that does not mistake endpoint cancellation or an
  interior extremum for convergence.

No frequency in this section is authorized by the present design.

## 14. Definition Of Done

T8ao is done only when the active metadata contract is complete and every
non-metadata array is proven exactly unchanged. T7bx is done only after an
independent direct-old/new review and an exact decision.

The overall repair stage is closed only by T0 after T7bx reports. Full-grid
production remains blocked.
