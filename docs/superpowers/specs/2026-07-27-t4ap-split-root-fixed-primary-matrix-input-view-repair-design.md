Its gate/config identities are absolute below `REPOSITORY_ROOT`, while the


## 4. Exact Split-Root Contract

For matrix producer and matching official audit, bind four separate
surfaces:

### 4.1 Canonical execution surface

The following must resolve exactly below the primary project root:

- runner path and runner SHA-256;
- imported `schwgw` source origins and exact implementation bytes;
- all five benchmark gate paths;
- frozen configuration path;
- optimized output root;
- legacy and golden inputs;
- fixed primary benchmark identity
  `46403a00663fc331a8b4c9941d66b2c597d2301f883c24804b5a01cd9bc06c48`.

The runner-derived project and output roots remain primary. A detached
runner, detached imported module, detached output, alternate config, or
root-specific benchmark identity is rejected for matrix work.

### 4.2 Detached input-working surface

The cwd and allowed cwd root must equal one fresh detached project inside
the authorized control root. “Clean” refers to the exact base checkout
*before* reviewed inputs are materialized; it must not be misread as
requiring an empty Git status after the complete-290 target view is built.
It must:

- be a regular non-symlink directory with exact realpath/dev/inode binding;
- begin as an exact clean Git checkout at HEAD `45face32...`;
- after input materialization, have no implementation-path drift and exactly
  the following reviewed status delta, with no other modified, deleted,
  renamed, copied, or untracked path:

  ```text
   M docs/handoffs/T7_current.md
  ?? docs/handoffs/archive/T7_2026-07-16_pre_t7ca_further_local_radial_review.md
  ?? docs/handoffs/archive/T7_2026-07-18_pre_t7cc_literal_failed_child_radial_review.md
  ?? docs/handoffs/archive/T7_2026-07-18_pre_t7cd_literal_failed_child_review.md
  ?? docs/handoffs/archive/T7_2026-07-20_pre_t7ce_another_bounded_local_radial_review.md
  ?? input_manifest.json
  ?? source_manifest.json
  ```

  The status must be parsed as status/path records and compared by exact
  Python code-point path ordering; raw substring, locale collation, and

- be disjoint from primary output, legacy, golden, canonical, driver,
  runtime overlay, and every earlier evidence root;

The mutable primary `docs/handoffs/T7_current.md` must remain byte/stat/

#### 4.2.1 Fresh manifest derivation

The historical witness manifests
`dfb23566...32a3` and `e2cbf431...f9d` are immutable evidence inputs only.
They include the historical detached absolute paths, devices, inodes and
modes, so their bytes and hashes are *not* expected identities for a fresh
matrix input root.

T4 must derive two new manifests without changing their reviewed meaning:

- the matrix source manifest retains schema
  `t4af_matrix_source_manifest_v1`, contains exactly one
  `immutable-during-audit` entry, and binds the actually executed primary
  runner with `source_path == target_path` at the canonical-primary absolute
  path and current stat/hash identity. Imported primary `schwgw` origins
  remain exhaustively bound by the separate frozen runtime/source probe and
  exact implementation manifest; the source manifest must not invent a
  second, discretionary source-file set;
- the matrix input manifest uses new schema
  `t4ap_matrix_input_manifest_v2`. Every entry has exactly the full witness
  input-entry key set, including `role` and `target_repository_path`, with
  `mutability == "read-only"`. It binds the same exact `290` roles,
  repository-relative targets, source paths, content hashes and sizes as the
  accepted witness contract, but records the fresh detached target absolute
  paths, devices, inodes, modes and nlinks. Targets are mutually
  inode-distinct and each source/target pair is inode-distinct.

The fresh input manifest must independently canonicalize, from records
containing exactly `role`, `sha256`, and `target_repository_path` in Python
code-point path order, to
`77927103da4d853e98dbe7c4d19a2198fb544349cf735bf63faaf02ca31dfd24`.
Its full-file hash is expected to differ from `e2cbf431...f9d`. Producer and
matching official audit must bind the same fresh manifest bytes and stat
identities. Reusing historical absolute target paths/inodes, accepting only
the current ASCII/file-set coincidence, or silently treating the historical
manifest hash as the fresh manifest hash fails closed.

Matrix validation must route each check to the correct root rather than
substituting `cwd` everywhere:

- runner-derived output, fixed benchmark identity, gate/config/legacy/golden
  paths, source manifest, implementation bytes and runtime
  `expected_project_root` use `canonical_project_root`;
- request `cwd`, `allowed_cwd_root`, exhaustive input-manifest targets and
  repository-relative consumed reads use `input_working_root`;
- the source-manifest validator requires its one target below the canonical
  root, while the input-manifest validator requires every target below the
  detached root and every source outside it;
- official audit revalidates the producer's exact two-root binding instead
  of collapsing either side back to its own cwd.

Any code path that still computes matrix runtime/source/manifest identity
from an undifferentiated `project_root == cwd` is a negative-test failure.

## 7. T4 Local Self-Remediation Rule

Within this reviewed Phase A, T4 must not return HOLD merely for a diagnosed
pre-execution, zero-science, artifact-local control defect in helper,
fixture, manifest, path bookkeeping, serialization, or test assembly.

T4 may iteratively correct such defects in fresh no-overwrite evidence
roots, preserving every failed root immutable, until the exact checkpoint
is reached. There is no arbitrary correction-count limit. Each correction
must have a new concrete diagnosis and must not be a blind retry.

T4 must stop and return HOLD before science only if correction would require
changing the runner, imported scientific source, runtime dependency,
complete-290 meaning, fixed primary identity, canonical data, scientific
criteria, frequency/order, or any destructive/global action.

Any future producer or official-audit child launch remains one-shot: a
post-launch failure consumes that unit and cannot be locally retried.
